# 🧘‍♀️ Wellness Buddy - React Frontend

A beautiful, modern React frontend for the Wellness Buddy application with a psychologically soothing design.

## ✨ Features

### 🎨 Design Philosophy
- **Soothing Color Palette** - Carefully chosen colors that promote calm and wellness
- **Smooth Animations** - Framer Motion animations for delightful interactions
- **Responsive Design** - Works perfectly on all devices
- **Accessibility First** - WCAG compliant design patterns

### 🚀 Key Features
- **Modern UI/UX** - Clean, intuitive interface with wellness-focused design
- **Real-time Chat** - Interactive chat with AI wellness companion
- **Mood Tracking** - Beautiful mood selection with visual feedback
- **Meditation Sessions** - Guided meditation with timer and progress
- **Break Reminders** - Smart break scheduling with notifications
- **Analytics Dashboard** - Visual progress tracking and insights
- **Leaderboard** - Friendly competition with team rankings
- **Gamification** - Points system and achievements

## 🛠️ Tech Stack

- **React 18** - Modern React with hooks
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Smooth animations and transitions
- **Lucide React** - Beautiful icon library
- **React Router** - Client-side routing
- **React Hot Toast** - Elegant notifications
- **Recharts** - Data visualization (ready for future use)

## 🚀 Quick Start

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Installation

1. **Navigate to frontend directory**
   ```bash
   cd frontend
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm start
   ```

4. **Open your browser**
   Navigate to `http://localhost:3000`

## 🔧 Customization

### Colors
Modify `tailwind.config.js` to customize the color palette:
```javascript
colors: {
  wellness: { /* wellness blues */ },
  calm: { /* calming greens */ },
  energy: { /* energizing oranges */ },
  meditation: { /* meditation purples */ }
}
```

### Animations
Customize animations in `tailwind.config.js`:
```javascript
animation: {
  'float': 'float 6s ease-in-out infinite',
  'breathing': 'breathing 4s ease-in-out infinite',
  // Add your own animations
}
```

### Components
All components are modular and can be easily customized:
- Modify component styles in `src/index.css`
- Update animations in individual components
- Add new wellness features
